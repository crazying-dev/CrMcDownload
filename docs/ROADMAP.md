## 验收基线

1. 空目录经镜像安装 1.14，全部文件 SHA-1 校验通过；
2. 安装 26.1.2（Java 25）并启动到主菜单；
3. 断网后已安装版本仍可启动，启动阶段零网络请求；
4. 离线包导入后可无网启动；
5. 客户端请求只发往 `download_base`；
6. 镜像二次请求命中缓存，`/metrics` 上游计数为 0；
7. `OffCraft.exe` 免 Python 完成安装与启动。
